# React Admin Dashboard

A reusable, modern admin dashboard built with **React, TypeScript, Tailwind CSS, and React Router**.

This project is designed as a common admin-panel foundation that can be integrated with different applications and business domains. The goal is to provide a clean, scalable, and maintainable dashboard structure following production-oriented frontend development practices.

Instead of creating an admin panel from scratch for every project, the dashboard can be reused and extended with application-specific modules.

## 🚀 Tech Stack

- React
- TypeScript
- Tailwind CSS
- React Router
- Lucide React
- Vite

## ✨ Features

- Responsive admin dashboard layout
- Collapsible sidebar navigation
- Dynamic sidebar menu configuration
- Nested submenu navigation
- Active route highlighting
- Public and admin route separation
- Protected admin route architecture
- Reusable layout components
- TypeScript-based type safety
- Reusable and maintainable component structure
- Light/Dark mode support
- Responsive UI using Tailwind CSS

## 🛠️ Getting Started

Clone the repository:

git clone <https://github.com/kartickdasmca/react-admin-dashboard-foundation>

Navigate to the project:

cd admin

Install dependencies:

npm install

Start the development server:

npm run dev

The application will be available at the local development URL provided by Vite.
